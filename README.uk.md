## Про проєкт

Це командний проєкт для курсу **Python Programming** у **Neoversity**.

Застосунок працює в терміналі та виконує роль локальної контактної книги й менеджера нотаток. Він дозволяє додавати, редагувати, видаляти, шукати та сортувати контакти, показувати найближчі дні народження, а також створювати й організовувати текстові нотатки за допомогою тегів. Дані зберігаються локально та автоматично відновлюються під час наступного запуску.

---

## Функціональність

* додавання контакту з ім'ям та одним або кількома номерами телефону;
* можливість додати до контакту дату народження, email та адресу;
* редагування всіх полів контакту або лише номерів телефону;
* видалення контактів;
* пошук за всіма полями контакту;
* пошук за окремим вибраним полем;
* перегляд усіх контактів із сортуванням за ім'ям, телефоном, email, адресою або датою народження;
* перегляд днів народження протягом заданої кількості днів;
* перевірка правильності номерів телефонів, email, дат народження та адрес під час введення;
* автодоповнення назв команд за допомогою `Tab`;
* локальне збереження стану застосунку після кожної розпізнаної команди;
* додавання, редагування, видалення та перегляд нотаток;
* додавання тегів до нотаток;
* пошук нотаток за назвою, текстом або тегами;
* пошук нотаток за конкретним тегом;
* сортування нотаток за тегами;

Для більшості команд необов'язково передавати всі аргументи одразу. Якщо якогось значення не вистачає, програма запитає його під час виконання команди.

## Встановлення

```bash
git clone https://github.com/NYurakh/project_python_group_5.git

cd project_python_group_5

python -m venv .venv

# Windows
.venv\Scripts\activate

source .venv/bin/activate
```

## Запуск

```bash
python main.py
```

Після запуску програма показує список доступних команд і очікує введення в рядку `>>>`.

Введіть `help`, щоб знову показати список команд, або `exit`, щоб зберегти дані та завершити роботу.

## Швидкий приклад

Додавання контакту відбувається інтерактивно:

```text
>>> add-contact

Name: Olena Kovalchuk

Phone: 0501112233

Another phone (Enter to finish): 0679876543

Another phone (Enter to finish):

Birthday DD.MM.YYYY (Enter to skip): 14.09.1994

Email (Enter to skip): olena.k@example.com

Address (Enter to skip): Lviv

✓ Contact added.
```

Обов'язковими є лише ім'я та один номер телефону. Інші поля можна пропустити, натиснувши `Enter`.

Якщо введене значення некоректне, програма показує помилку валідації та повторно запитує це поле. Де це можливо, попереднє значення залишається в рядку введення, тому для виправлення однієї цифри не потрібно вводити все поле заново.

## Команди

### Загальні

| Команда | Що робить                         |
| ------- | --------------------------------- |
| `help`  | Показати список команд            |
| `hello` | Показати привітання               |
| `exit`  | Зберегти дані та завершити роботу |

### Контакти

| Команда                                   | Що робить                                                                |
| ----------------------------------------- | ------------------------------------------------------------------------ |
| `add-contact`                             | Додати новий контакт через інтерактивне введення                         |
| `edit-contact [name]`                     | Редагувати ім'я, телефони, дату народження, email та адресу контакту     |
| `edit-contact-phones [name]`              | Редагувати лише номери телефону                                          |
| `remove-contact [name]`                   | Видалити контакт                                                         |
| `show-all-contacts [field]`               | Показати всі контакти з можливістю сортування за вибраним полем          |
| `show-contact-phones <name>`              | Показати номери телефону вибраного контакту                              |
| `search-contacts [text]`                  | Шукати текст серед усіх полів контактів                                  |
| `search-contact-by-field [field] [value]` | Шукати значення лише в одному вибраному полі                             |
| `upcoming-birthdays [days]`               | Показати контакти, у яких день народження буде протягом заданого періоду |

### Нотатки
### Нотатки

| Команда | Що робить |
|---|---|
| `add-note` | Додати нову нотатку з назвою, текстом та необов'язковими тегами |
| `show-all-notes` | Показати всі збережені нотатки |
| `show-note [ID]` | Показати одну нотатку за її ID |
| `edit-note [ID]` | Редагувати назву, текст і теги нотатки |
| `remove-note [ID]` | Видалити нотатку |
| `search-notes [text]` | Шукати нотатки за назвою, текстом або тегами |
| `search-notes-by-tag [tag]` | Знайти нотатки за конкретним тегом |
| `sort-notes-by-tags` | Показати нотатки, відсортовані за тегами |

## Валідація

| Поле            | Поточне правило                                                                                                                          |
| --------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| Ім'я            | Обов'язкове під час додавання або редагування через CLI; повинно бути унікальним у контактній книзі                                      |
| Телефон         | Рівно 10 цифр; дублікати номерів усередині одного контакту не допускаються; контакт повинен мати щонайменше один номер                   |
| Email           | Повинен відповідати стандартному формату на зразок `name@example.com`; адреси, що закінчуються на `.ru`, `.su` або `.рф`, не приймаються |
| Дата народження | Формат строго `DD.MM.YYYY`, дата повинна існувати в календарі                                                                            |
| Адреса          | Необов'язкова, але якщо значення вказано, воно не може бути порожнім або складатися лише з пробілів                                      |

Валідація для `Phone`, `Email`, `Birthday` та `Address` реалізована безпосередньо у відповідних класах полів у `models/fields.py`.

## Керування введенням

| Клавіша                            | Дія                                                                                                              |
| ---------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| `Tab`                              | Автодоповнення назви команди в головному рядку введення; деякі запити з вибором також підтримують автодоповнення |
| `Enter` у необов'язковому полі     | Пропустити значення, очистити його під час редагування або завершити введення списку                             |
| `Ctrl+C` під час виконання команди | Скасувати поточну команду та повернути повідомлення `Cancelled.`                                                 |

## Зберігання даних

Стан застосунку зберігається у файлі `.pkl`.

Файл містить `AppContext`, включно з `AddressBook` та `NoteBook`.

Директорія `userdata` створюється автоматично під час першого збереження. Файл із даними виключений із Git, тому особисті контакти та нотатки не потрапляють у репозиторій.

Застосунок зберігає свій стан після кожної розпізнаної команди та автоматично завантажує його під час наступного запуску.

## Структура проєкту

```text
project_python_group_5/

├── main.py                     # REPL-цикл, обробка команд, збереження
├── app_context.py              # Спільний стан застосунку
├── requirements.txt
│
├── models/
│   ├── fields.py               # Name, Phone, Email, Birthday, Address
│   ├── contact.py              # Модель контакту та логіка пошуку/сортування
│   └── note.py                 # Модель нотатки, теги, редагування та пошук
│
├── books/
│   ├── address_book.py         # Колекція контактів, пошук, сортування, дні народження
│   └── note_book.py            # Колекція нотаток, пошук, теги та сортування
│
├── cli/
│   ├── parser.py               # Парсинг команд на основі shlex
│   ├── command_registry.py     # Метадані та групи команд
│   ├── command_helpers.py      # Допоміжна логіка введення та обробки помилок
│   ├── contact_commands.py     # Обробники команд для контактів
│   ├── note_commands.py        # Команди для роботи з нотатками
│   ├── general_commands.py     # help / hello / exit
│   └── view.py                 # Rich-таблиці та повідомлення в терміналі
│
└── storage/
│   └── storage.py              # Збереження та завантаження через pickle
│
└── userdata/
    └── assistant_data.pkl      # Локальні дані, створюються автоматично
```

Кілька деталей реалізації:

* введення команд обробляється через `shlex`, тому імена з пробілами, наприклад `"Olena Kovalchuk"`, сприймаються як один аргумент;
* команди реєструються в `cli/command_registry.py` разом із підказкою щодо використання та описом;
* меню `help` і автодоповнення команд формуються на основі цього реєстру;
* таблиці та повідомлення про успіх або помилки виводяться за допомогою `rich`;
* `prompt_toolkit` використовується для інтерактивного введення та автодоповнення.
